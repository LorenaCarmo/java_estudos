# Exercícios de Java

Repositório dedicado à prática da linguagem Java, com exercícios desenvolvidos durante meus estudos em Ciência da Computação.

O objetivo é consolidar os fundamentos da linguagem, desenvolver o raciocínio lógico e acompanhar minha evolução por meio da prática.

## Tecnologias e ferramentas

- Java (JDK 25 LTS)
- Visual Studio Code
- Git e GitHub

## Conteúdos

- Sintaxe básica e estrutura de programas
- Variáveis e tipos de dados
- Operadores
- Entrada e saída de dados
- Estruturas condicionais
- Estruturas de repetição
- Arrays e matrizes
- Métodos
- Programação Orientada a Objetos (POO)
- Tratamento de exceções
- Collections

## Como executar

**Pré-requisito:** JDK instalado.

Clone o repositório:

```bash
git clone https://github.com/LorenaCarmo/java_exercicios.git
```

Entre na pasta de um exercício:

```bash
cd java_estudos/exercicio_01
```

Compile o código:

```bash
javac Main.java
```

Execute:

```bash
java Main
```
